# 待测试

- 画布生图/视频：画布节点和配置节点生成时以当前选择的模型为准，并同步到对应生图/视频/文本/音频字段；需验证选择 `seedance-2.0` 时请求模型不再被历史 `seedance-2.0-fast-480p` 覆盖。
- 视频生成兼容：视频工作台和画布按模型适配 Seedance、Grok、Omni、Sora、Veo 的中转协议，其中 Veo 多图使用 `reference_image_urls`；需按已配置模型逐项验证文生视频、图生视频和支持的参考素材组合。
- 视频长任务：创建后保存公开任务 ID 和幂等键，刷新或短暂查询失败后可继续轮询原任务；需验证继续查询不会重新创建任务、失败不扣费、成功只扣费一次。
- 视频媒体地址：工作台只接受当前中转域名或 `https://image.52token.org/v1/video-content/*` 返回的视频，并在浏览器本地保存 Blob；需验证页面、下载文件和错误提示均不暴露上游 URL。
- 52Token 生图工作台：默认渠道改为 `https://image.52token.org`，预置 Image2 OpenAI 调用格式和 Gemini banana 调用格式，需验证用户填写分组 Key 后可直接生图。
- OpenAI 兼容生图：新增同步优先的自动兼容模式，若同步接口明确要求异步则创建一次异步任务并轮询结果；需验证苍源异步接口、原 Image2 同步接口和 Gemini 生图接口均可用。
- 批量生图：新增并发限制，默认并发 5、最高 10；需验证批量生成不会一次性打满所有请求，失败项只在用户手动重试时重新创建任务。
- Docker 部署：Compose 默认绑定 `127.0.0.1:15731`，需配合 Nginx 根路径反代，同时确认 `/v1/images/*` 和 `/v1beta/models/*` 仍由 sub2api 处理。
- 提示词库：新增 `xianyu110/awesome-gptimage2` 来源，加载结果会过滤空提示词、无图和重复条目，需验证提示词中心和画布内提示词弹窗分页滚动正常。
- Codex App 插件文档：新增插件安装教程，区分 AI 自动安装、手动安装和本仓库开发调试安装；同步优化插件 README 与技能说明。
- 配置与用户偏好：每个模型渠道新增 OpenAI / Gemini 调用格式选择，默认 OpenAI，切换默认格式时同步更新默认 Base URL；渠道 Tab 增加紧凑醒目的提醒，说明模型是否可选需要到“模型”Tab 选择。
- Gemini 调用格式：支持拉取 Gemini 模型列表，并用于文本问答、在线 Agent 工具调用、基础生图和图生图请求。
- 音频和视频生成：选择 Gemini 调用格式时先给出不支持提示，仍需使用 OpenAI 兼容渠道。
- WebDAV 同步：移除 Next.js 转发代理和连接方式选择，改为浏览器前端直接连接 WebDAV 服务。
- 提示词库：移除 Next.js route 抓取和服务端内存缓存，改为浏览器前端直连 GitHub 原始文件并缓存到 IndexedDB。
- 提示词库：移除已 404 的 `EvoLinkAI/awesome-gpt-image-2-API-and-Prompts` 来源。
- 前端构建：移除 Next.js，改为 Vite + React Router，并将前端目录调整为 `pages` / `components` / `stores` / `lib` / `layouts` / `styles`，需验证首页、图片/视频工作台、素材、提示词库和画布路由跳转。
- 前端构建：修复 TypeScript 严格检查下的构建报错。
- Vercel 部署：新增 `web` 和 `docs` 两个子项目的 Vercel 配置，需分别验证静态前端和文档站部署。
